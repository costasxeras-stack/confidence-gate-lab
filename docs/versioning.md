# Versioning

- MAJOR: a rebuild, or a change in how the app is used.
- MINOR: a new feature or visible improvement, for example per-intent thresholds.
- PATCH: a bug fix or wording change.

The version must match in `package.json`, the top of `CHANGELOG.md`, the **Current version** line in `README.md` and the version badge in `index.html`. Each release is also published as a GitHub release.
